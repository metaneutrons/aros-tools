# Community code of conduct

The aros-tools community collaborates on technically difficult systems work.
Disagreement is expected; harassment and personal attacks are not.

## Expected behavior

- Discuss evidence, contracts and trade-offs rather than motives or identity.
- Give reproducible feedback and allow others to correct mistakes.
- Respect differing experience levels, backgrounds and communication styles.
- Keep private security reports, personal information and credentials private.
- Accept maintainer decisions about project scope while remaining free to
  document a technical disagreement constructively.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate disruption, impersonation and publishing private correspondence or
security details without permission are not accepted in project spaces.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub
profile or, when the concern is security-related, through `SECURITY.md`.
Maintainers may edit or remove content, limit participation, temporarily ban or
permanently exclude a participant. Reports will be handled proportionately and
with as much confidentiality as the circumstances permit.

This policy applies in the repository, its documentation and project-related
public or private communication where someone represents the project.
