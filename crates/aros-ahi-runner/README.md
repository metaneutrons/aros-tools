# `aros-ahi-runner`

`aros-ahi-runner` executes one external AHI build from a validated,
content-addressed contract generated by the transpiler. The contract parser,
input-integrity validation, staging, CMake configure/build execution, product
validation, source audit, and publication are separate library modules; the
binary is only the process boundary.

The runner fails closed when the contract identity, an input snapshot, an
allowed path, or an expected product differs. It does not act as a general
external-project runner and must not infer ambient host state.

`AHI_SOURCE_ROOT` owns the AHI sources and their input manifest;
`AHI_ENGINE_ROOT` owns `manifests/ahi-<mode>.install` in the selected tools
engine. The product inventory is never loaded from a checkout's legacy
`cmake/` directory. Both owners and the exact mode-specific manifest identity
are checked before execution. Older generated contracts without the engine
owner must be regenerated by configuring with the matching tools suite.

Human diagnostics are the default. `--diagnostic-format json` selects the
shared `aros-tool-diagnostics-v1` document. Local logs are disabled by default
and require `--log-file`; environment names use the `AROS_AHI_` prefix.
